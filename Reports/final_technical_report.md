# Final Technical Report

## Project Title
AI-Based Student Performance Prediction

---

# 1. Project Overview

The AI-Based Student Performance Prediction project is developed to predict the academic performance of students using Machine Learning techniques. The system analyzes student-related information such as study hours, attendance, and previous academic scores to estimate future performance.

---

# 2. Objectives

- Predict student academic performance using AI.
- Improve accuracy through Machine Learning.
- Provide an easy-to-use prediction interface.
- Demonstrate AI deployment using backend and frontend technologies.
