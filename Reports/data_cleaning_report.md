# Data Cleaning Report

## Project
AI-Based Student Performance Prediction

## Dataset
student_raw_data.csv

## Objective
To improve data quality by removing inconsistencies,
missing values, duplicate records and formatting issues.

---

## Before Cleaning

- Raw dataset was collected and stored in the data folder.
- Dataset was checked for missing values and duplicate records.
- Data types and consistency across fields were verified.

## Cleaning Steps Performed

1. Checked missing values
2. Removed duplicate records
3. Verified data consistency
4. Prepared cleaned dataset for model training

---

## After Cleaning

- Cleaned dataset saved as:

`data/processed/student_cleaned_data.csv`

- Dataset is ready for further AI model training and analysis.
