# Project Demonstration Guide

## Project Name

AI-Based Student Performance Prediction

## Project Workflow

1. Load student dataset.
2. Clean the dataset.
3. Train the Machine Learning model.
4. Start the backend server.
5. Open the frontend interface.
6. Enter student details.
7. Click Predict.
8. View predicted student performance.

---

## Input

- Student Name
- Study Hours
- Attendance
- Previous Score

---

## Output

The system predicts the student's academic performance as:

- Good Performance
- Average Performance
- Poor Performance
